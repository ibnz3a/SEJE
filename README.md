# SEJE Artesanías 🧵

Catálogo profesional de artesanías hechas a mano en Colombia.

## 🌐 Visita la página web
[https://ibnz3a.github.io/SEJE/](https://ibnz3a.github.io/SEJE/)

## 📋 Descripción
Este repositorio contiene el sitio web oficial de **SEJE Artesanías**, un catálogo de productos artesanales elaborados con fibra natural por artesanos colombianos. El sitio incluye:
- Catálogo de productos con precios y referencias
- Modo oscuro/claro
- Soporte bilingüe (Español/Inglés)
- Contacto directo por WhatsApp y correo

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (vanilla)
- GitHub Pages (hosting)
